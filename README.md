## Featured Projects

### [Plane Deployment on AWS ECS Fargate](https://github.com/Saabdulle/plane-aws-ecs-deployment)

Deployed the Plane project management platform using **Terraform, Docker, Amazon ECS Fargate, ECR and CircleCI**. Automated infrastructure provisioning and application deployments across three Availability Zones, reducing deployment time by **84%** compared with the manual process.

### [AWS EKS Deployment with GitOps](https://github.com/Saabdulle/aws-eks-gitops-deployment)

Built an automated Kubernetes deployment environment using **Pulumi, Terraform, EKS, Argo CD, CircleCI and GitHub Actions**. Integrated **Prometheus, Grafana and Amazon SES** for monitoring and notifications.

### [Smart Home Microservices on AWS](https://github.com/Saabdulle/smart-home-microservices-terraform)

Used **Terraform** to provision AWS infrastructure for a distributed microservices application, including **EC2, DynamoDB, VPC networking, IAM, Auto Scaling and an Application Load Balancer**.
